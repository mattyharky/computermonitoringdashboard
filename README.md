# computermonitoringdashboard
This is a vibe coded project using Gemini Neon at the time of production.  

**Dashboard01** is taken from a real hardware monitoring device sold on Amazon for £100+ and provides the software only alternative.  
If you have a spare monitor attached to your computer you can use this instead of an expensive alternative.

1.  **psutil** is required to run the python code.  Use **pip install psutil** to install the library.
2.  Then run the code with python dashboard01.py
3.  Then launch the web page called **dashboard01.html**

This is the latest version which will be updated soon with a more robust version.
